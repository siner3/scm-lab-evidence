

|**Term**|**Your definition in one sentence**|
|-|-|
|Repository|A storage location that contains a project's files, source code and version history.|
|Working tree (working directory)|The local directory where user can view, create and modify project files.|
|Staging area (index)|A temporary area where user can select and prepare changes before committing them to the repository.|
|Commit|A saved snapshot of changes in the repository, usually accompanied by a message describing the changes.|
|Branch|A separate line of development that allows developers to work on different features without affecting the main branch.|
|Merge|The process of combining changes from one branch into another branch.|
|Remote|A version of the repository hosted on another computer or server, allowing developers to collaborate and share code.|
|Push/Pull/Clone|Push uploads local commit to a remote repository. Pull downloads and integrated remote changes into the local repository and Clone create a local copy of a remote repository.|
